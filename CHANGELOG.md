# Changelog

## 0.1.0

First release: an asynchronous client for Web Search, Web Search Premier, Broad Search, News Search, Business Search, Pulse Search, Place Search, Image Search, Video Search, Design Search, Extract, Embedding and VL Embedding, with typed requests and responses checked against the public OpenAPI spec, local checks of the required inputs, and the same retry and timeout rules as the Python, TypeScript and Go SDKs.
